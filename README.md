# ParchePlan U
## ParchePlan U es una aplicación web que tiene como fin organizar planes entre los estudiantes de la universidad
## La idea principal de la pagina web es crear grupos, proponer planes, votar por la mejor opcion y lo mas importante, confirmar la asistencia.
---
# Funcionalidades de la pagina
## Crear y unirse a parches
## Crear los planes
## Votar por el plan que mas te guste
## Confirmar tu asistencia 
## Ver los resultados de votación 
## Ver el ranking de participacion de las personas 
---
# Tecnologías 
## Para la parte del Frontend se utilizaron datos mockeados simulando la API.
## Se trabajo con React, TailwindCSS, JavaScript, Servicios API simulados 
### Nota: La aplicación web esta muy bien preparada para la integración con el Backend. 
---
# Ejecución 
## En la terminal se ejecutaran los siguientes comando en su respectico orden: 
### "npm install"
### "npm run dev"
